# Caesar Cipher - PRODIGY_CS_01

## Overview
This project implements the Caesar Cipher algorithm using Python. It allows users to encrypt and decrypt messages by providing a custom shift value.

## Features
- Encrypt text
- Decrypt text
- Supports uppercase and lowercase letters
- Preserves spaces, numbers, and symbols

## Requirements
- Python 3.x

## How to Run

```bash
python caesar_cipher.py
```

## Example

Input:

```
Enter Message: HELLO WORLD
Enter Shift Value: 3
```

Output:

```
Encrypted Message: KHOOR ZRUOG
Decrypted Message: HELLO WORLD
```
