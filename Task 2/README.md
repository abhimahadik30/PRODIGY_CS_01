# PRODIGY_CS_02

## Task-02: Pixel Manipulation for Image Encryption

### Description

This project encrypts and decrypts images using pixel manipulation. Each RGB value is modified using a user-provided encryption key.

### Features

- Image Encryption
- Image Decryption
- User-defined Key
- Simple Pixel Manipulation

### Technologies Used

- Python
- Pillow Library

### How to Run

```bash
pip install pillow
python image_encryptor.py
```

### Output

- encrypted_image.png
- decrypted_image.png
